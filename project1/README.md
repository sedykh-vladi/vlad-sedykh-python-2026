# Проект 1. Окупилось ли повышение цен в марте 2026

Папка собирает вспомогательные материалы проекта. Сдаваемые файлы лежат там, где их требует задание.

| Файл | Где лежит | Что это |
|---|---|---|
| Ноутбук | `notebooks/project1.ipynb` | весь расчёт: приёмка данных, метрики, факторное разложение, отток, графики |
| Записка | `ЗАПИСКА-ПРОЕКТ-1.md` (корень) | вывод на одну страницу для заказчика |
| Декларация ИИ | `ДЕКЛАРАЦИЯ-ИИ-ПРОЕКТ-1.md` (корень) | какие инструменты ИИ использовались и для чего |
| Графики | `project1/figures/` | картинки, которые сохраняет ноутбук; их использует записка |
| Функции | `src/prime/checks.py`, `metrics.py`, `factors.py` | проверки данных, отток, цепные подстановки и каскад |

Почему не всё в одной папке: путь ноутбука и файлов в корне задан в задании, а функции должны лежать
в пакете `src/prime`, иначе не сработает `from prime... import ...`.

## Как воспроизвести

```bash
uv sync
uv run jupyter lab
```

Открыть `notebooks/project1.ipynb` и выполнить Kernel -> Restart Kernel and Run All Cells.
Нужен файл `.env` со строкой подключения к базе (см. корневой README).
