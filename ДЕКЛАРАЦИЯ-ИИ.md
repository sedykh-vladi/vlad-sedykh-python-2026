## Чем пользовался

ИИ использцется только в заданиях, которые были сгенерены с помощью ИИ. (Определяется по вербальным признакам, как длинные знак тере, заглавный текст, сранные знак препинания и лексографический порядок слов)
Если задание было написано без использование ИИ, то и выполняется но мной без использования ИИ

deepseek используется на протяжении всех заданий:
1. Поиковой инсурмент 
2. Отладчик кода
3. Консультант по промежуточным выводам
4. Джун разработчик для скелета кода
5. Агрегатор знаний 
6. Аналитик для анализа написанного другими агентом задания

## Существенные подсказки

<!--
  Существенная — та, после которой в работе появился код или вывод,
  которого без неё не было бы. Исправленная опечатка — не существенная.

  По каждой: что спрашивали, что получили, что с этим сделали.

В рамках работы использую как ИИ агента на каждом шаге, сверяю свое понимание с тем, что выдает агент
Весь код написан через запросы к агенту
Весь код отлажен через запросы к агенту 
Все понимание сфрмировано через общение с агентом 
Поиск наиболее эффекивного решения через агента

Агент участвует на каждом этапе: 
1. Пишет код 
2. Объясняет
3. Проверяет исправления 
4. Присылает рашифровки того, что написал агент в задании, если не понятно
